# rihla-spike — technical test (throwaway)

Purpose: prove that Next.js + Payload CMS + Supabase (PostgreSQL + Storage) + Netlify work together
for Rihla, in French, English and Arabic (right-to-left). This code will NOT become the real site.

- `/fr/destinations/djerba`, `/en/...`, `/ar/...`: public test pages
- `/admin`: Payload admin dashboard

Settings (environment variables) are listed in `.env.example`. Real values live only in Netlify.
See the report: `PROJECT_BLUEPRINT/14_TECHNICAL_TEST_REPORT.md` in the Rihla project.
